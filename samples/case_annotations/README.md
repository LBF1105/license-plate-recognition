# 三组案例标注图说明

每个案例分别用两个方案各跑一遍，共 6 张标注图。命名规则：`caseN_场景_方案.jpg`。

- 方案一 = 集成式（HyperLPR3），对应 `integrated`
- 方案二 = 分步式（YOLOv8 + LPRNet），对应 `two_stage`

## 结果对照

| 案例 | 场景 | 真实号码 | 方案一（集成式） | 方案二（分步式） |
| --- | --- | --- | --- | --- |
| 案例 1 | 停车场多车牌 | 冀A9F3J6、苏E67A12、冀A8C309 | 冀A9F3J6、冀A8C309、苏E67A12 ✓ | 冀A9F3J6、苏E67A12、冀A8C309 ✓ |
| 案例 2 | 倾斜 23° | 皖AS821X | 皖AS821X ✓ | 粤1L3GB21K ✗（全错） |
| 案例 3 | 完全水平，省份字 | 川J6MS71 | 浙J6MS71 ✗（省份字错） | 浙J6MS71 ✗（省份字错） |

> 判定标准：整牌字符全部一致才算正确。
