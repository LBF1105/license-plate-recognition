# 角点回归拉正（Corner Regression Deskew）

这一篇讲方案二（YOLOv8 + LPRNet）里**如何把倾斜 / 斜视拍出来的车牌，按它的真实四个顶点透视拉成长方形**再送去识别。

这是项目里唯一一条能真正"找到车牌四个顶点"的路。前面尝试过的纯几何方法全部失败，过程记录在文末，值得先看一眼，免得重复踩坑。

---

## 1. 为什么需要它

YOLOv8 的 detect 头输出的是**轴对齐矩形**：

```
(x_center, y_center, width, height)
```

四个标量，数学上没有"旋转"这一维。一张倾斜 θ 的车牌，被它框出来是一个比车牌本身更宽、更矮的外接矩形：

| 车牌倾角 θ | 外接框宽高比 | 说明 |
| --- | --- | --- |
| 0° | 3.10 | 标准车牌比例 |
| 5° | 2.52 | 已经开始变矮 |
| 10° | 2.13 | |
| 20° | 1.63 | 几乎接近正方形 |
| 30° | 1.32 | |

直接把这个外接矩形裁下来送进 LPRNet，等于**带着一大堆背景，还把车牌内容拉伸变形**——因为 `recognizer.preprocess` 会把它 `cv2.resize` 到 168×48，宽高比被强行改成 3.5。

要拉正，就必须知道车牌自己的四个顶点。而 detect 头给不出来。

## 2. 纯几何方法为什么不行（已全部实测）

在动手训练之前，试过六条"不改模型、从图里算顶点"的路，全部在 300 张 CCPD 上做了端到端评测：

| 方法 | 角度误差中位 | 拿到四边形的比例 | 300 张识别率 |
| --- | --- | --- | --- |
| 不做任何拉正（baseline） | — | — | **91.0%** |
| 用检测框宽高比反解角度 | 3.0° | 100%（假点） | 82.0% |
| 霍夫直线找水平长边估角 | 1.9° | 100% | 86.7% |
| 霍夫四条边求交点 | — | 37/300 | 85.0% |
| 颜色连通域 + IoU 挑选 + 四边形拟合 | — | 102/300 | 89.7% |
| 颜色连通域 + minAreaRect | — | 295/300 | 78.0% |
| 字符竖直笔画估角 | 5.3° | — | 79.7% |
| 真值四角点（作弊，仅供测上限） | 0° | 300/300 | **92.0%** |

三个原因是结构性的：

1. **车牌和车身同色**。蓝牌对蓝色/青色车漆、绿牌对浅绿车身，HSV mask 一开就把车身一起吞掉，越往外扩越糟。
2. **裁剪图里没有背景**。YOLO 框紧贴车牌，crop 内 88–98% 的像素都是车牌颜色，`findContours` 抓到的"最大轮廓"就是整张裁剪图的边界，`minAreaRect` 退化成水平矩形、角度恒为 0。
3. **检测框本身就不准**。车牌基本水平的 175 张图上，框的宽高比中位数是 **2.77**、标准差 **0.349**——换算成角度大约 ±6°。而倾斜造成的比例变化也是这个量级，两者根本无法区分。

最后一行很关键：**只要顶点是对的，拉正就有效**（92.0%，且大倾斜场景从 62.5% 提到 87.5%）。所以问题不在"拉正"这件事，而在"怎么拿到顶点"。

## 3. 角点回归网络

既然算不出来，就让一个小网络学出来。

### 结构

```
输入 192×64×3（BGR，拉伸到固定尺寸，标签同步归一化）
  ↓ 5 层 stride-2 卷积 + BN + ReLU   32 → 64 → 96 → 128 → 128
  ↓ Flatten
  ↓ Linear(6144→128) + ReLU + Dropout(0.1)
  ↓ Linear(128→8)
输出 8 个标量 = 4 个角点的 (x, y)，坐标归一化到 [0,1]
```

只有 **约 2 MB**，CPU 上单张 2–3 ms。

两个设计要点：

- **不套 sigmoid**。检测框比车牌小，实测 **46/300** 的角点落在裁剪图之外，必须允许输出超出 [0,1]。代码里最终只 clip 到 [-1.5, 2.5]。
- **输出层带先验初始化**。把最后一层 bias 设成标准车牌四角 `[0.06, 0.12, 0.94, 0.05, 0.94, 0.95, 0.06, 0.88]`、weight 乘 0.05，让网络从"一个合理的车牌形状"开始拟合。这一条是收敛的关键——不加的话训练 200 epoch 的 loss 只到 0.026，加完能到 0.006，角点误差从 1.62% 降到 0.71%。

### 训练

数据来自 `data/test_images` 的 300 张 CCPD 图，**不额外下载数据集**：

1. 用 YOLOv8 跑检测，按 5% 外扩裁剪；跳过双层牌；
2. 从 CCPD 文件名第 4 段解析真值四角点（`x1&y1_x2&y2_x3&y3_x4&y4`），换算到裁剪图坐标；
3. 5 折交叉验证 + 全量训练两条线都跑。

训练配置：AdamW（lr=2e-3, wd=1e-4）+ CosineAnnealingLR，SmoothL1Loss(beta=0.05)，batch 32，200 epoch。数据增强：旋转 ±9°、缩放 0.88–1.12、平移 ±6%、亮度抖动、25% 概率高斯模糊。

```bash
# 全量训练，产出 weights/corner_net.pt
python scripts/train_corner_net.py --epochs 200 --rebuild

# 5 折交叉验证（评估泛化误差）
python scripts/train_corner_net.py --epochs 140 --folds 5
```

### 精度

角点误差 = 四个顶点到真值的平均距离 ÷ 车牌宽度。

| 模型 | 中位 | 均值 | <3% 占比 |
| --- | --- | --- | --- |
| 5 折交叉验证（OOF，未见数据） | 1.04% | 1.24% | 97% |
| 全量模型（部署用） | **0.71%** | 0.76% | 100% |

## 4. 集成方式：候选 + 择优

拉正不是"替换"，而是**多出一个候选**。`TwoStagePipeline._candidates()` 现在的顺序是：

1. **原图裁剪**（永远保底，保证不会比原来差）；
2. **角点拉正图**（`CornerResult.valid` 为真时才有）；
3. 角点失效时，退回纯几何 `deskewer.candidates()[1:]` 兜底。

每个候选都跑一次 `recognize_with_score()`，**取 CTC 置信度最高的那个**。置信度是解码后保留字符位上 softmax 最大概率的均值。

这样做的效果是"只赚不赔"：拉正图只有在自己更自信时才会被采纳。

### 端到端结果

300 张 CCPD：

| 指标 | baseline | 角点拉正 + 择优 |
| --- | --- | --- |
| 整牌正确率 | 91.0% (273/300) | **94.7% (284/300)** |
| 字符准确率 | 97.6% | **98.9%** |
| 平均耗时 | 41 ms/张 | **40 ms/张** |
| ≤5°（236 张） | 94.1% | 95.3% |
| 6–15°（56 张） | 82.1% | **92.9%** |
| >15°（8 张） | 62.5% | **87.5%** |

自采集的 8 张湘牌（`data/test_images_xiang`）：

| 方案 | 正确率 |
| --- | --- |
| 方案一 HyperLPR3 | 7/8 = 87.5% |
| 方案二 baseline（拉正前） | 4/8 = 50.0% |
| **方案二 + 角点拉正** | **7/8 = 87.5%** |

剩下 16 张错误里，超过一半是**省份字混淆**（川→浙、皖→赣/冀/闽/陕/粤、藏→苏、琼→鲁）。这是 78 类字符表里最难的 31 个字形，和几何校正无关——要再往上走，得靠省份白名单约束或更强的识别器，不是继续调角点。

## 5. 配置与用法

`config/config.yaml`：

```yaml
two_stage:
  preprocessing:
    corner_net:
      enabled: true
      weights: weights/corner_net.pt   # 也可以是目录，目录下所有 .pt 会做集成
      device: cpu
    deskew:
      enabled: true                    # 角点失效时的纯几何兜底
```

命令行：

```bash
# 默认开启，自动读取配置
python scripts/run_two_stage.py --source data/test_images

# 显式关闭角点拉正，退回 baseline
python scripts/run_two_stage.py --source data/test_images --no-corner

# 同时关掉角点与几何兜底，得到最原始的 baseline
python scripts/run_two_stage.py --source data/test_images --no-corner --no-deskew
```

权重缺失时会自动降级：打印提示并改用纯几何兜底，不会崩溃。

## 7. 已知局限

- **只看单张裁剪图**。角点精度依赖裁剪图里车牌边框的可见程度，车牌被遮挡或裁掉一个角时会偏。
- **省份字仍然是主要错误源**。角点拉正把几何问题解决了，剩下的瓶颈转移到识别器对形近字的区分能力上。
- **训练数据只有 300 张**。5 折 OOF（1.04%）和全量模型（0.71%）的差距说明模型仍有一定过拟合；如果之后能接入完整 CCPD 训练集，泛化误差还有下降空间。
